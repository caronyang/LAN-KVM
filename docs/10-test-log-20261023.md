## Gate 2：跨機 P0 — **部分 PASS**

A（master，`192.168.68.69`）→ B（client／service，`192.168.68.68`）：

```powershell
# B
```

### 判定

| 項目 | 結果 |
|------|------|
| UDP 握手／`client online` | PASS |
| A 右邊界進入、B 左邊界對應高度 | PASS |
| A 鍵盤在 B 正確輸入 | PASS |
| B 注入健康度（`inject_fail=0`） | PASS |
| B 本地滑鼠推到左邊界回切 | **不支援（by design）** |

### 發現：B 的本地滑鼠不能回切

`poc.rs` 的 client 只在累積 master 送來的 `dx <= -30` 時送 Release：

```rust
virtual_x = virtual_x.saturating_add(packet.a);
let left_exit = entry_edge == 1 && virtual_x <= -30;
```

client 模式不掛本地 hook，所以 B 的滑鼠/觸控板不會產生 Release。**正確回切方式**：

1. 移動 **A 的實體滑鼠向左**約 100px；
2. 或按 `Ctrl+Alt+Shift+Q`；
3. 或結束 A 的 `poc`。

這是 P1「local takeover／雙向控制」要解的問題，不是網路或注入 bug。

### 待補測

- [ ] A 滑鼠左移回切（`OFF (edge)` / `released at edge`）
- [ ] `Ctrl+Alt+Shift+Q`
- [x] 停掉 B service 後的 `client not reachable`（A 立即恢復本地操作）
